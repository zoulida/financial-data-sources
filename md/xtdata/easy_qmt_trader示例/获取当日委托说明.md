# 获取当日委托使用说明

## 功能概述

`easy_qmt_trader` 类提供了 `sync_orders()` 方法来获取当日委托信息。

## 方法说明

### sync_orders()
```python
def sync_orders(self):
    """
    同步当日委托信息，返回 DataFrame。
    """
```

**返回字段说明:**
- `账号类型`: 账号类型（通常为 "STOCK"）
- `资金账号`: 资金账号
- `证券代码`: 股票代码（如 "600031.SH"）
- `订单编号`: 委托订单ID
- `委托类型`: "买入" 或 "卖出"
- `委托数量`: 委托数量（股数）
- `成交数量`: 已成交数量（股数）
- `委托价格`: 委托价格
- `委托状态`: 委托状态（见下方说明）
- `策略名称`: 策略名称
- `备注`: 订单备注

**委托状态说明:**
- `已报`: 已申报，未成交
- `部分成交`: 部分成交
- `已成`: 全部成交
- `已撤`: 已撤销

## 使用示例

### 基本使用
```python
from easy_qmt_trader_zld import easy_qmt_trader

# 初始化交易接口
trader = easy_qmt_trader(
    path=r'D:\国金QMT\userdata_mini',
    account='55009640',
    session_id=123456
)

# 连接交易系统
if trader.connect() == 0:
    # 获取当日委托
    orders_df = trader.sync_orders()
    
    if not orders_df.empty:
        print(f"获取到 {len(orders_df)} 条委托")
        print(orders_df.to_string())
    else:
        print("无委托数据")
```

### 按状态筛选
```python
# 获取所有委托
orders_df = trader.sync_orders()

# 筛选未成交委托
pending_orders = orders_df[orders_df['委托状态'].isin(['已报', '部分成交'])]

# 筛选已成交委托
completed_orders = orders_df[orders_df['委托状态'] == '已成']

# 筛选已撤销委托
cancelled_orders = orders_df[orders_df['委托状态'] == '已撤']
```

### 统计分析
```python
orders_df = trader.sync_orders()

# 委托状态统计
status_counts = orders_df['委托状态'].value_counts()
print("委托状态统计:")
for status, count in status_counts.items():
    print(f"  {status}: {count} 条")

# 按股票统计
stock_stats = orders_df.groupby('证券代码').agg({
    '委托数量': 'sum',
    '成交数量': 'sum',
    '委托价格': 'mean'
})
print(stock_stats)
```

## 注意事项

1. **连接要求**: 调用 `sync_orders()` 前必须先调用 `connect()` 并确保连接成功
2. **QMT 状态**: 确保 QMT 客户端已启动并登录
3. **路径配置**: 确保 QMT 用户数据路径配置正确
4. **权限要求**: 确保账号有查询委托的权限

## 错误处理

常见错误及解决方法：

1. **连接失败 (-1)**
   - 检查 QMT 客户端是否启动
   - 检查路径配置是否正确
   - 检查账号配置是否正确

2. **无委托数据**
   - 可能当日确实没有委托
   - 检查账号是否正确
   - 检查是否有查询权限

3. **编码问题**
   - 确保终端支持 UTF-8 编码
   - 或使用英文输出
