# 上涨缩量选股策略

## 策略概述
本策略旨在寻找长期横盘整理后出现缩量上涨的股票，结合量价关系和均线系统进行选股。

## 选股逻辑

### 1. 基础筛选条件
- 股票范围：沪深A股（60/00开头）
- 价格区间：3元 ≤ 股价 ≤ 18元
- 市值区间：30亿 ≤ 市值 < 200亿

### 2. 技术指标要求

#### 长期整理特征
- 120日振幅 ≤ 20%
- 120日内窄幅震荡日数（日振幅≤5%）≥ 80天

#### 近期量价特征
- 5日K线中阳线 ≥ 3根
- 5日累计涨幅：3% ~ 10%
- 量能特征（满足其一）：
  - 5日均换手率 ≤ 1.2%
  - 5日均量 ≤ 120日均量的90%

#### 涨幅控制
- 现价 ≤ 120日均线 * 1.15
- 现价 ≤ 20日均线 * 1.08

#### 股性要求
- 250日内7%以上大阳线 ≥ 3次
- 60日平均换手率 ≥ 1%

### 3. 排除条件
- ST股票
- 最近5日有跌停的股票

## 输出结果
- 结果按120日振幅（升序）和5日累计收益（升序）排序
- 输出文件：`data/result/上涨缩量_选股_YYYYMMDD.csv`

## 数据源
- 使用xtdata或本地缓存获取行情数据
- 复权方式：前复权

## 使用说明
直接运行`main.py`即可生成选股结果。

## 注意事项
- 本策略适合中短线操作
- 建议结合市场环境和其他技术指标进行综合判断
- 回测表现不代表未来收益，投资需谨慎
