# 热点新闻采集与评分

一键运行：

```
python main.py
```

## 功能
- 并发抓取（微博热搜、百度实时热点、知乎热榜、清博 10w+、抖音、快手），限 20 连接，UA 池化，重试 + 1-3s 随机延迟。
- 同标题去重（TF-IDF + 余弦相似度阈值 0.75），合并热度指标。
- 评分：M、T、A、S（彩色控制台输出）。
- 调度：自动区分开市/非开市（A股 09:30-11:30, 13:00-15:00 UTC+8），开市每 15 分钟，非开市每 2 小时。
- 持久化：SQLite（hot_raw, hot_score）。

## 目录
- main.py：入口与总流程
- crawler.py：各平台爬虫（aiohttp 并发）
- scorer.py：去重与评分逻辑
- scheduler.py：开市/非开市调度
- db.py：SQLite 持久化

## 依赖
见 requirements.txt。若无需额外安装，直接运行也可（Python 内置 sqlite3）。

## 说明
- 微博阅读增量基于 1 小时前的历史记录差分计算；首次抓取时增量为 0。
- 抖音/快手 24h 视频条数受反爬影响，若无法获取则为 0，不影响程序运行。
