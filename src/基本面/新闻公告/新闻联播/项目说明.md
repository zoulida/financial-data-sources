# 新闻联播文字版下载工具 - Python实现

## 项目概述

本项目是参考GitHub项目 [xin-wen-lian-bo](https://github.com/DuckBurnIncense/xin-wen-lian-bo) 的Python实现版本，用于自动下载央视《新闻联播》节目的文字版内容。

## 与原项目的对比

### 原项目（JavaScript/Node.js）
- 使用Node.js + jsdom实现
- 自动抓取每日新闻联播
- 保存为Markdown格式
- 通过GitHub Actions自动运行

### 本项目（Python）
- 使用Python + requests + BeautifulSoup4实现
- 支持命令行和代码调用两种方式
- 支持多种输出格式（JSON、TXT、Markdown）
- 增加了智能容错和备用方案
- 支持获取详细新闻内容

## 核心功能

1. **自动获取最新新闻联播** - 从央视网抓取最新一期的新闻联播文字版
2. **多种保存格式** - 同时保存为TXT、JSON和Markdown格式
3. **智能容错** - 多种备用方案，确保能获取到内容
4. **详细内容获取** - 可选择获取所有新闻的详细内容
5. **完整日志** - 详细的运行日志，方便调试
6. **命令行支持** - 支持多种命令行参数

## 技术实现

### 数据抓取流程

1. **获取新闻列表页**
   - 首先尝试访问指定日期的新闻列表页：`http://tv.cctv.com/lm/xwlb/day/{date}.shtml`
   - 如果失败，则访问新闻联播首页获取最新一期

2. **解析新闻链接**
   - 从页面中提取包含"新闻联播"且包含"VIDE"的链接
   - 这些链接指向具体的新闻内容页

3. **获取新闻内容**
   - 访问新闻内容页
   - 提取标题（从`<title>`标签）
   - 提取日期（从`.laiyuan`元素）
   - 提取内容（从`.video_brief`元素）

4. **保存数据**
   - JSON格式：完整的结构化数据
   - TXT格式：纯文本，便于阅读
   - Markdown格式：参考原GitHub项目的格式

## 使用示例

### 基本使用

```bash
# 下载最新的新闻联播
python -m src.新闻公告.新闻联播.main

# 下载昨天的新闻联播
python -m src.新闻公告.新闻联播.main --yesterday

# 下载指定日期
python -m src.新闻公告.新闻联播.main --date 20251123
```

### 高级功能

```bash
# 获取所有新闻的详细内容（会花费较长时间）
python -m src.新闻公告.新闻联播.main --details

# 显示详细日志
python -m src.新闻公告.新闻联播.main --verbose

# 指定输出目录
python -m src.新闻公告.新闻联播.main --output "/path/to/save"
```

## 改进点

相比原GitHub项目，本Python实现增加了以下改进：

1. **更强的容错能力** - 多种备用方案，即使某个URL失效也能获取内容

3. **更丰富的输出格式** - JSON、TXT、Markdown三种格式
